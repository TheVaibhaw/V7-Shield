# Future feature mock-ups (not served)

UI prototypes from the first demo phase, kept for reference while those features are built.
They use sample data from `data/demo-data.php` and **do not reflect real scans**.

They are outside `frontend/`, so the web server never serves them, and they won't run as-is.
To revive a page, move it back into `frontend/pages/`, register it in `frontend/config/app.php`, and replace the demo data with backend calls.

Planned features: quarantine, file integrity / baselines, scheduled scans, CMS (WordPress/Joomla) checks, database checks, reports/export, notifications, projects management.
